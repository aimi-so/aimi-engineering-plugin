**The mechanical form of the principle is that only TWELVE of the 269 open a file at all**, and every one of them is named in the table above: `validate_story_exists`, the three `jq empty` probes (`cmd_normalize_verification`, `cmd_normalize_status`, `cmd_normalize_waves`), `_split_detect_describe`, `_directory_source_plugin_dir`, `_directory_source_installed_version`, `_roadmap_require`, `_roadmap_require_contracts`, `cmd_roadmap_write_handoff`, `cmd_prime_cache`'s own directory-source version lookup, and `cmd_version`. `cmd_detect_parent_branch`'s new call is not among them — `winners` is a bash array the same function already built, not a document arriving from outside. Everything else either constructs JSON from values the script already holds or reads back something the same function just produced. If you are weighing a new `jq` line, that is the question to ask of it: does a document arrive here that this script did not write in this call?

**`cmd_version` reading `plugin.json` was left as `jq` deliberately, and `bfcf0ff` is where that was decided.** That commit's finding was that NONE of the four version/cache verbs — `version`, `check-version`, `cleanup-versions`, `prime-cache` — cross into Python, for the locating-the-CLI reason above. `cmd_version` is additionally the clearest case of the principle: `plugin.json` is a manifest that ships with the plugin, not a lifecycle document a user or a concurrent session mutates. Its single `jq -er 'if (.version | type) == "string" then .version else empty end'` covers a missing key, a non-string key and a parse failure in one expression and one branch.

It only ever looks inside fenced ` ```bash ` blocks, because that is what an agent runs literally (see `test-command-blocks.sh`'s own scope, root `CLAUDE.md` § Testing) — and `review.md`'s Design Fidelity **Trigger gate** condition 1 is a real `jq -r … $TASKS_FILE` read written as inline prose (a single-backtick span), never inside a fence, so no story's capture and no test suite has ever counted it. **Why each of the four extractor-visible sites still opens a file, verified against the current tree rather than copied forward from the story that left it:**
