# command-size-baseline.txt — grandfathered byte budgets for commands/
# (including commands/references/), for skills/**/SKILL.md, and for
# agents/**/*.md, enforced by test-command-size.sh.
#
# Format, tab-separated:  <path>  <budget in bytes>
#
# A path with no prefix is relative to commands/ (`execute.md`,
# `references/forge-contract.md`); a path starting with `skills/` or
# `agents/` is relative to the plugin directory. Two relpath roots rather
# than one so that the twelve budgets recorded before skills/ joined the
# corpus did not have to move, and the same two roots absorb agents/ too —
# see test-command-size.sh's header for the rule and where it is applied.
#
# Every budget is a multiple of 4096 (BUDGET_STEP in test-command-size.sh):
# the smallest one that holds the file. The budget is a RATCHET in steps, not
# a ceiling in one direction only: growing past it fails ("over budget"),
# and shrinking into the step below fails too ("stale budget"). That second
# failure is deliberate -- it forces the commit that shrinks one of these
# files by a step to lower its number in the same diff, so a budget can never
# sit a whole step generous after the file that earned it got smaller. A
# number that is not a multiple of the step fails as "malformed budget"; the
# finding always names the number to write instead.
#
# The steps replaced exact byte counts. With exact counts every edit to one
# of these files, however small, had to touch this baseline too, and most of
# those touches recorded growth as routine. A step is crossed rarely enough
# that crossing one is worth a reviewer's attention.
#
# Every corpus file NOT listed here is held to DEFAULT_CEILING (16384 bytes,
# also a multiple of the step) instead. The files below are the ones that
# already exceeded that ceiling when they joined the corpus; a global rule
# strict enough to catch a new bloated file cannot also pass them, so they
# get an individual budget instead of a shared one. A file that shrinks back
# under the ceiling loses its line.
#
# A budget here is a ratchet against further growth and says nothing about
# whether the file is the right size, and this suite measures bytes and
# cannot see a line count at all.
#
# Measured against the source .md files under commands/, never against
# install.sh's OpenCode translation. translate_command_body() prepends a
# fixed ~4862-byte agent-invocation preamble to some command bodies and not
# others, so measuring post-translation would blend "this file carries too
# much prose" with "the installer added its own fixed boilerplate" -- see
# plugins/aimi-engineering/CLAUDE.md § Command Conventions for where a
# command's instruction content belongs, and
# commands/references/context-budget.md for the classification this budget
# backs.
