# command-blocks-baseline.txt — known findings for test-command-blocks.sh
#
# Format, tab-separated:  <check>  <command file>  <key>
#   check : syntax | portability | loop-scope | unassigned
#   key   : the block's enclosing heading (syntax, portability)
#           the variable name             (loop-scope, unassigned)
#
# Blocks are keyed by heading rather than by a marker in the markdown because
# install.sh translates command bodies for OpenCode by pure string
# substitution — anything embedded in the file itself would ship to users.
#
# A line here is a promise that someone looked. The suite fails when a listed
# finding stops firing, so this file shrinks as things are fixed; it cannot
# quietly accumulate. Delete the line when you fix the thing.

# --- syntax -----------------------------------------------------------------
# Not defects. Three blocks use the <angle-bracket> placeholder convention,

# ```bash block whose heredoc body itself contains ``` fences, so extraction
# truncates it mid-command-substitution. ([BRACKET] placeholders, the far more
# common convention in these files, parse fine and need no entry here.)

# SUSPECTED LIVE DEFECT, not accepted noise. The exact shape of blocking
# finding B3 (execute.md Step 0.9 read $split_file with no loop to set it),
# which shipped and had to be found by hand:
#
#   plan.md     PROJECT_PATH   — the per-entry base-branch block under "Derive
#       and Patch Metadata Fields" reads $PROJECT_PATH, which only the Phase 3e
#       validation loop ~100 lines earlier ever assigns. Note this variable
#       moved here from the `unassigned` list when that loop was added: making
#       a block a real loop makes its outputs loop-scoped, so loop-less
#       downstream consumers start failing too.
#
# This is listed so the suite can be green and enforcing today. It should
# be fixed and deleted, not renewed.
#
# execute.md SPLIT_BRANCH (Phase-Mode Paired Split's "Create Split Worktrees")

# by folding SPLIT_WORKTREE_PATH into the same per-member JSON record that
# Derive and Validate Split Branch Names assigns inside its own loop.
